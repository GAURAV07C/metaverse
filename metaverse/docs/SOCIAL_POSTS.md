# Social Launch Posts

Use these posts when sharing the project. Prefer "Gather-inspired" or "Gather-like" instead of claiming official Gather Town affiliation or exact 1:1 parity.

## LinkedIn Post

I built an open-source Gather-inspired virtual office.

It has a canvas-based map, realtime multiplayer movement, rooms and spots, proximity/room-based audio-video, screen share, meeting mode, chat, reactions, portals, invite links, and a Studio-style map editor.

The goal is simple: make remote collaboration feel spatial again, where you can walk around, join a room, sit at a spot, talk to nearby teammates, and customize the office.

Tech stack:
- React + Vite
- Canvas map rendering
- WebSocket realtime server
- mediasoup SFU for audio/video/screen share
- Express API
- Prisma/Postgres
- Zustand + TanStack Query

It is open source, so you can use it, test it locally, or contribute improvements.

Current focus:
- smoother WebRTC performance
- better map editor UX
- more production-ready scaling
- stronger Gather-like workspace interactions

If you are interested in virtual offices, realtime collaboration, WebRTC, or open-source product building, contributions are welcome.
